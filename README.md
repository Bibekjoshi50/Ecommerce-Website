# 🛒 E-Commerce Website

A simple and responsive e-commerce website built using **HTML, CSS, and JavaScript**. This project demonstrates a clean shopping interface with a modern design and responsive layout.

## 🌐 Live Demo

https://bibekjoshi50.github.io/Ecommerce-Website/

## 🚀 Features

- Responsive Design
- Modern User Interface
- Product Showcase
- Shopping Cart UI
- Mobile Friendly
- Easy Navigation

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
